# インストールガイド

このガイドは、sorus を自分の PC に入れて、起動・更新・削除するまでの手順書です。

* 必要なのは、Windows または Mac の PC だけです。プログラミングの道具やサーバーは要りません。
* 書いた記事などのデータは、アプリとは別の場所に保存されます。更新しても消えません。
* 入れた後の使い方は、記事を書く人は [執筆・編集・AI連携ガイド](writing_guide.md)、サイトを設定・管理する人は [サイト管理者ガイド](site_admin_guide.md) を読んでください。

## 1. 用意するもの

| 立場 | 用意するもの |
| :--- | :--- |
| 記事を書く人（ライター） | PC（Windows または Mac）だけ |
| サイトを公開する人 | PC ＋ 公開先のどれか1つ（レンタルサーバーの契約、Cloudflare のアカウント、または手作業でのアップロード） |
| 公開サーバーを使う場合だけ（公開サーバー連携） | 上の2つ ＋ VPS とドメイン（[公開サーバーを使うガイド](decoupled_sync_guide.md)） |

* インターネットにつながっている必要があるのは、インストールと公開のときだけです。記事はオフラインでも書けます。
* 管理者のパスワード（PC の管理者権限）は要りません。

## 2. Windows に入れる

1行のコマンドを貼り付けて入れます。この方法がいちばん警告が出にくく、おすすめです。

1. スタートボタンを右クリックし、「ターミナル」または「Windows PowerShell」を開きます。
2. 次の1行をコピーします。

   ```powershell
   irm https://github.com/ryuzi/sorus/releases/latest/download/install.ps1 | iex
   ```

3. 開いた画面に貼り付けて、Enter を押します。
4. 「sorus のインストールを始めます。」から順に進み、「完了しました。」と出るまで待ちます。
5. sorus のウィンドウが開きます。[4. はじめて起動したとき](#4-はじめて起動したとき) に進んでください。

この1行が行うこと:

* PC に合うファイルを選んでダウンロードします。
* ファイルが壊れていないこと、書き換えられていないことを確かめます。確かめられなければ中止します。
* `%LOCALAPPDATA%\Programs\sorus\sorus.exe` に置き、スタートメニューとデスクトップに「sorus」のショートカットを作ります。
* sorus を起動します。

> Windows 11 で「スマート アプリ コントロール」がオンになっている PC では、sorus は開けません。くわしくは [11. 困ったとき](#11-困ったとき) を見てください。

## 3. Mac に入れる

1. 「アプリケーション」→「ユーティリティ」の「ターミナル」を開きます。
2. 次の1行をコピーします。

   ```sh
   curl -fsSL https://github.com/ryuzi/sorus/releases/latest/download/install.sh | sh
   ```

3. ターミナルに貼り付けて、Enter を押します。
4. 「sorus のインストールを始めます。」から順に進み、「完了しました。」と出るまで待ちます。
5. sorus のウィンドウが開きます。Google Chrome も Microsoft Edge も入っていない Mac では、Safari などいつものブラウザのタブで sorus の画面が開きます。[4. はじめて起動したとき](#4-はじめて起動したとき) に進んでください。

この1行が行うこと:

* Mac の CPU（Apple シリコンか Intel か）に合うファイルを選んでダウンロードします。
* ファイルが壊れていないこと、書き換えられていないことを確かめます。確かめられなければ中止します。
* ホームフォルダの中の「アプリケーション」フォルダ（`~/Applications/sorus.app`）に置きます。
* sorus を起動します。

## 4. はじめて起動したとき

sorus のウィンドウに「はじめに」の画面が出ます。2つのことを決めると、すぐに記事を書き始められます。

1. **あなたの名前とパスワード**
   * 表示名: 記事の書き手として表示される名前です。
   * ユーザー名: ログインに使います。半角の英字・数字と「-」「_」で3〜32文字です。
   * パスワード: 8文字以上です。忘れないように控えてください。
2. **サイト名**: あとで「設定」→「サイト設定」から変えられます。

「はじめる」を押すと、ホームの画面が開きます。

* ここで作ったアカウントは管理者になり、書く・設定する・公開するのすべてができます。
* sorus は、この PC の中だけで動きます。インターネットからは見えません。

### 前の PC のデータを引き継ぐとき

「はじめに」の画面の下にある「バックアップから始める」を使います。

1. 前の PC で作ったバックアップ（`sorus_backup_` で始まる .zip ファイル）を用意します。自動バックアップのフォルダ（[サイト管理者ガイドの「自動バックアップ」](site_admin_guide.md#自動バックアップ)）にもあります。
2. 「バックアップファイルを選ぶ」でそのファイルを選びます。
3. 「このバックアップから始める」を押します。
4. ログインの画面に変わったら、前の PC で使っていたユーザー名とパスワードでログインします。

## 5. 2回目からの起動と終了

### 起動する

| PC | 起動のしかた |
| :--- | :--- |
| Windows | スタートメニューまたはデスクトップの「sorus」 |
| Mac | ホームフォルダの「アプリケーション」フォルダにある「sorus」 |

* 起動すると、sorus の画面が専用のウィンドウで開きます。アドレス欄やタブの無いウィンドウです。
  * Windows は Microsoft Edge、Mac は Google Chrome・Microsoft Edge・Chromium のどれかを使って開きます。
  * Chrome も Edge も入っていない Mac では、Safari などいつものブラウザのタブで開きます。使い方は同じです。
* すでに起動しているときにもう一度起動すると、動いている sorus のウィンドウを開きます。
* 画面のアドレスは `http://127.0.0.1:8780/admin` のような形です。8780 が使われているときは、別の番号になります。

### 終了する

sorus のウィンドウを閉じると、10秒ほどで sorus が終了します。

* まだサイトに反映していない予約投稿があるときだけ、終了してよいかの確認が出ます。「予約をすべて反映してから終了する」を選ぶと、sorus は画面を出さずに動き続け、最後の予約をサイトに反映してから終了します。「今すぐ終了する」を選ぶと、すぐに終了します（[サイト管理者ガイドの「起動と終了」](site_admin_guide.md#起動と終了)）。
* 予約した記事を公開先にその時刻に出すには、その時刻に sorus が動いている必要があります（[執筆・編集・AI連携ガイドの「予約投稿」](writing_guide.md#予約投稿)）。公開サーバーで予約した記事は、sorus を閉じていてもその時刻に公開されます。

画面のメニューから終了することもできます。

1. 画面の右上の、自分の名前（名前 ▼）を押します。
2. 「sorus を終了」を押します。
3. 「sorus を終了しますか？」と出たら、確かめて終了します。予約投稿が残っているときは、「予約をすべて反映してから終了する」「今すぐ終了する」「やめる」から選びます。

## 6. 更新する

新しい版が出ると、ホームの画面に「新しいバージョン（v1.2.3 など）があります」というお知らせが出ます。

1. 右上の名前 ▼ から「sorus を終了」を押して、sorus を終了します。
2. Windows は PowerShell（またはターミナル）、Mac はターミナルを開きます。
3. お知らせに表示された1行を「コピー」で写し、貼り付けて Enter を押します。インストールのときと同じ1行です。
4. 「完了しました。」と出て、新しい版の sorus が起動すれば終わりです。

* 書いた記事などのデータはそのまま残ります。データはアプリとは別の場所（[8. データの置き場所](#8-データの置き場所)）にあるためです。
* お知らせの「閉じる」を押すと、その版のお知らせは出なくなります。さらに新しい版が出ると、また出ます。
* 更新は自動では行いません。お知らせが出ていなくても、同じ1行を実行すれば最新版になります。
* sorus が動いたままだと、置き換えに失敗することがあります。そのときは「sorus を終了」で終了してから、もう一度1行を実行します。

## 7. 予備の方法: ファイルをダウンロードして入れる

1行のコマンドがうまくいかないときだけ使います。sorus はまだ署名のないアプリなので、この方法では PC が警告を出します。

1. [sorus のリリースのページ](https://github.com/ryuzi/sorus/releases/latest) を開きます。
2. 「Assets」から、自分の PC に合うファイルをダウンロードします。

   | PC | ファイル |
   | :--- | :--- |
   | Windows（ふつうの PC） | `sorus-<版>-windows-amd64.zip` |
   | Windows（ARM の PC） | `sorus-<版>-windows-arm64.zip` |
   | Mac（Apple シリコン） | `sorus-<版>-darwin-arm64.zip` |
   | Mac（Intel） | `sorus-<版>-darwin-amd64.zip` |

3. Zip を展開し、中の `sorus.exe`（Windows）または `sorus`（Mac）をダブルクリックします。

### 警告が出たとき

| PC | 出る警告 | 開き方 |
| :--- | :--- | :--- |
| Windows | 「Windows によって PC が保護されました」 | 「詳細情報」を押してから「実行」を押す |
| Mac | 「開けません」などの警告 | 「システム設定」→「プライバシーとセキュリティ」を開き、「このまま開く」を押す |

* 警告の文言やボタンの名前は、OS の版によって少し違うことがあります。
* この方法では、スタートメニューのショートカットや Mac の「アプリケーション」フォルダへの登録は行いません。次からも、展開したファイルから起動します。
* 次の版からは、2章・3章の1行で入れ直すことをおすすめします。データはそのまま引き継がれます。

## 8. データの置き場所

データは OS の決まった場所に保存されます。どのフォルダから起動しても、同じ場所を使います。

| PC | データの場所 | フォルダの開き方 |
| :--- | :--- | :--- |
| Windows | `%LOCALAPPDATA%\sorus` | エクスプローラーのアドレス欄に `%LOCALAPPDATA%\sorus` と入力して Enter |
| Mac | `~/Library/Application Support/sorus` | Finder の「移動」→「フォルダへ移動」に `~/Library/Application Support/sorus` と入力 |

中にある主なもの:

| 名前 | 中身 |
| :--- | :--- |
| `database.db` | 1つ目のサイトの記事・設定・アカウントなど |
| `uploads` | 1つ目のサイトの記事の画像 |
| `attachments` | 1つ目のサイトの記事に添付した資料（PDF など） |
| `themes` | 取り込んだ独自テーマのフォルダ（2つ目以降のサイトでは `sites/<id>/themes`） |
| `sites.json` | サイトの一覧（2つ目のサイトを作ったときに作られます） |
| `sites/<id>/` | 2つ目以降のサイトのデータ。それぞれのフォルダの中に、1つ目のサイトと同じ `database.db`・`uploads`・`attachments` などが作られます |
| `削除したサイトのバックアップ` | 自動バックアップの保存先を決めていないサイトを削除したとき、削除の直前に作られるバックアップが入るフォルダ |
| `sorus.log` | sorus の動作の記録。困ったときに、技術者に見せると原因が分かることがあります |
| `パスワード再設定コード.txt` | 「パスワードを忘れたとき」に一時的に作られるファイル（2つ目以降のサイトでは `sites/<id>/` の中に作られます。[執筆・編集・AI連携ガイド](writing_guide.md#パスワードを忘れたとき)） |

* 1つ目のサイトのデータ（`database.db`・`uploads`・`attachments` など）は、2つ目のサイトを作ったあとも動かさず、このデータの場所そのものに置かれたままになります（[サイト管理者ガイドの「複数のサイトを使う」](site_admin_guide.md#8-複数のサイトを使う)）。
* このフォルダの中のファイルを直接動かしたり消したりしないでください。データを守るには、画面の「設定」→「バックアップ」を使います。
* PC が壊れたときに備えて、[自動バックアップ](site_admin_guide.md#自動バックアップ) を設定しておいてください。

## 9. 使っている版を確かめる

ターミナル（Mac）または PowerShell（Windows）で次を実行すると、版（例: `v1.2.3`）が表示されます。

**Mac**

```sh
~/Applications/sorus.app/Contents/MacOS/sorus --version
```

**Windows**

```powershell
& "$env:LOCALAPPDATA\Programs\sorus\sorus.exe" --version | Write-Output
```

Windows の sorus は画面を持たないアプリとして作られているため、最後の `| Write-Output` を付けて結果を表示させます。

## 10. sorus を削除する

1. 右上の名前 ▼ から「sorus を終了」を押して、sorus を終了します。
2. アプリを削除します。

   | PC | 削除するもの |
   | :--- | :--- |
   | Windows | `%LOCALAPPDATA%\Programs\sorus` フォルダ、スタートメニューとデスクトップの「sorus」ショートカット |
   | Mac | ホームフォルダの「アプリケーション」フォルダにある「sorus」 |

3. 記事などのデータも消すときだけ、[8. データの置き場所](#8-データの置き場所) のフォルダを削除します。**消したデータは戻せません。** 先にバックアップを取ってください。

アプリだけを消した場合、あとで入れ直すと、残っているデータをそのまま使えます。

## 11. 困ったとき

**Q. Windows で、1行を貼り付けても sorus が開けません。「スマート アプリ コントロール」と表示されます。**
A. Windows 11 の「スマート アプリ コントロール」がオンの PC では、署名のないアプリはどの方法でも開けません。7章の予備の方法でも開けません。署名付きの版が出るまでお待ちください。この機能の設定を変えるかどうかは、PC を管理している人と相談してください。

**Q. 「ダウンロードできませんでした」と出ます。**
A. インターネットにつながっているか確かめて、もう一度実行してください。会社や学校のネットワークでは、ダウンロードが止められていることがあります。

**Q. 「ダウンロードしたファイルが壊れているか、書き換えられている可能性があるため、インストールを中止しました」と出ます。**
A. 安全のために止めています。時間をおいてもう一度実行してください。すでに入っている sorus はそのまま使えます。

**Q. 「sorus を置き換えられませんでした」と出ます。**
A. sorus が動いています。右上の名前 ▼ から「sorus を終了」で終了してから、もう一度1行を実行してください。

**Q. sorus のウィンドウが開きません。**
A. もう一度 sorus を起動してください。動いている sorus があれば、そのウィンドウを開きます。それでも開かないときは、[8. データの置き場所](#8-データの置き場所) の `sorus.log` を技術者に見せてください。

**Q. パスワードを忘れました。**
A. ログインの画面の「パスワードを忘れたとき」から、新しいパスワードを決められます（[執筆・編集・AI連携ガイド](writing_guide.md#パスワードを忘れたとき)）。

**Q. 別の PC に引っ越したい。**
A. 前の PC でバックアップを作り、新しい PC に sorus を入れて「はじめに」の画面の「バックアップから始める」で読み込みます（[4. はじめて起動したとき](#前の-pc-のデータを引き継ぐとき)）。

## 12. 技術者向け付録

ここから先は、技術者向けの補足です。ふだんの利用には必要ありません。

### Linux に入れる

Mac と同じ1行で入ります。

```sh
curl -fsSL https://github.com/ryuzi/sorus/releases/latest/download/install.sh | sh
```

`~/.local/bin/sorus` とアプリの一覧用の `~/.local/share/applications/sorus.desktop` を置きます。データは `$XDG_DATA_HOME/sorus`（未設定なら `~/.local/share/sorus`）です。予備の方法は `sorus-<版>-linux-amd64.tar.gz`（ARM は `linux-arm64`）を展開して `sorus` を実行します。

### インストールスクリプトの環境変数

| 変数 | 意味 |
| :--- | :--- |
| `SORUS_VERSION` | 版を固定する（例: `v1.2.3`）。省略時は最新版 |
| `SORUS_RELEASE_BASE` | ダウンロード元の URL |
| `SORUS_NO_LAUNCH` | 空でなければ、入れた後に起動しない |

### ファイルの確かめ方

リリースの `SHA256SUMS` に全ファイルのハッシュがあります。

### デスクトップ版の動き

* 待ち受けは `127.0.0.1` だけです。優先ポートは 8780 で、使用中なら空いているポートを使います。`Host` ヘッダーが `127.0.0.1:<port>` / `localhost:<port>` 以外の要求は 403 にします。
* データディレクトリは環境変数 `SORUS_DATA_DIR` で差し替えられます。
* `--server` か `--public-only` を付けたとき、または `PUBLIC_ONLY` / `ENV_FILE` / `DB_PATH` のどれかが設定されているときは、デスクトップ版でも従来のサーバーとして動きます。
* デスクトップ版の `sorus backup` などのコマンドは、データディレクトリのデータを使います。保存先を省略したバックアップは、サイトのフォルダの `backups`（1つ目のサイトはデータディレクトリの `backups`、2つ目以降は `sites/<id>/backups`）に置きます。サイトが2つ以上あるときは、`sorus sites` で `id` を確かめて `--site <id>` を付けます（[運用保守ガイド](operations_guide.md)）。

### ソースから動かす

ソースコードは公開リポジトリ `ryuzi/sorus` から取得します。ふつうは 2章・3章の1行か [リリースのページ](https://github.com/ryuzi/sorus/releases/latest) から入れてください。

Go 1.25 以降が必要です。

```bash
git clone https://github.com/ryuzi/sorus.git
cd sorus
go mod download
go run . --desktop
```

`--desktop` を付けると、配布版と同じデスクトップモードで起動します。開発用の `make dev`（`admin` / `dev-admin-pass`、`local_dev.db`）は [開発者ガイド](developer_guide.md) を見てください。
